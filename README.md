# SPI Solutions

Página web de SPI Solutions: desarrollo de software, sistemas administrativos, apps móviles, automatizaciones y consultoría para negocios en Ecuador.

- Next.js 16 (App Router) + TypeScript, sin librerías de UI: estilos propios en `src/app/globals.css`.
- Publicada en Vercel: https://spi-solutions.vercel.app
- `referencia/prototipo.html`: prototipo original en HTML, de donde salió el diseño.

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```
